
# Role-Based Access Control (RBAC) – Permissions Matrix

## 1. Χρήστες (Users)

| Εργαλείο | Student | Teacher | Admin | Αιτιολόγηση |
|---|---|---|---|---|
| `list_users` | Deny | Deny | Allow | Οι φοιτητές δεν βλέπουν δεδομένα άλλων χρηστών. (Δες Ασάφεια 1) |
| `get_user` | Allow (μόνο εαυτό) | Allow (όλους) | Allow | Οι φοιτητές βλέπουν μόνο τα δικά τους στοιχεία. Οι καθηγητές βλέπουν βασικά στοιχεία άλλων, ενώ τα ευαίσθητα αφαιρούνται μέσω της `redact`. |
| `update_user` | Allow (μόνο εαυτό + συγκεκριμένα πεδία) | Allow (μόνο εαυτό) | Allow | Οι φοιτητές αλλάζουν μόνο τηλέφωνο/διεύθυνση. Κανείς πλην Admin δεν αλλάζει ρόλους. |
| `reset_password` | Deny (στο chat) | Deny (στο chat) | Allow | Απαιτεί παλιό κωδικό που το εργαλείο δεν ζητάει. (Δες Ασάφεια 2) |
| `create_user` / `delete_user` | Deny | Deny | Allow | Μόνο ο Admin διαχειρίζεται λογαριασμούς. |
| `enroll_user` | Deny | Deny | Allow | Οι φοιτητές δεν γράφονται μόνοι τους και οι καθηγητές δεν κάνουν εγγραφές. |

## 2. Μαθήματα & Υλικό (Courses & Materials)

| Εργαλείο | Student | Teacher | Admin | Αιτιολόγηση |
|---|---|---|---|---|
| `list_courses` | Deny | Allow | Allow | Οι φοιτητές βλέπουν μόνο όσα μαθήματα είναι εγγεγραμμένοι. (Δες Ασάφεια 3) |
| `get_course` | Allow (αν είναι εγγεγραμμένος) | Allow (αν διδάσκει) | Allow | Έλεγχος ιδιοκτησίας (Ownership). |
| `read_forum` / `post_forum` | Allow (αν είναι εγγεγραμμένος) | Allow (αν διδάσκει) | Allow | Έλεγχος ιδιοκτησίας. |
| `add_material` / `post_announcement` | Deny | Allow (αν διδάσκει) | Allow | Μόνο οι διδάσκοντες του μαθήματος μπορούν να προσθέτουν υλικό και ανακοινώσεις. |

## 3. Εργασίες & Βαθμοί (Assignments & Grades)

| Εργαλείο | Student | Teacher | Admin | Αιτιολόγηση |
|---|---|---|---|---|
| `list_assignments` | Allow (αν είναι εγγεγραμμένος) | Allow (αν διδάσκει) | Allow | Ορατό σε όσους συμμετέχουν στο μάθημα. |
| `submit_assignment` / `submit_exercise` | Allow (μόνο εαυτό, αν είναι εγγεγραμμένος) | Deny | Deny | Το `student_ref` πρέπει να αντιστοιχεί στον ίδιο τον χρήστη. |
| `get_submissions` | Deny | Allow (αν διδάσκει) | Allow | Οι φοιτητές βλέπουν μόνο τις δικές τους υποβολές μέσω του `get_grades`. |
| `grade_submission` / `set_final_grade` / `set_component_grade` / `publish_grades` | Deny | Allow (αν διδάσκει) | Allow | Μόνο καθηγητές και Admin αλλάζουν και δημοσιεύουν βαθμούς. |
| `get_grades` | Allow (μόνο εαυτό) | Allow (αν διδάσκει) | Allow | Οι φοιτητές βλέπουν μόνο τους δικούς τους βαθμούς. (Δες Ασάφεια 4) |
| `get_gradebook` | Deny | Allow (αν διδάσκει) | Allow | Μόνο καθηγητές και Admin βλέπουν το βαθμολόγιο. |

## 4. Ασκήσεις (Exercises)

| Εργαλείο | Student | Teacher | Admin | Αιτιολόγηση |
|---|---|---|---|---|
| `list_exercises` | Allow (αν είναι εγγεγραμμένος) | Allow (αν διδάσκει) | Allow | Ορατό στους συμμετέχοντες του μαθήματος. |
| `get_exercise` | Deny | Allow (αν διδάσκει) | Allow | Το εργαλείο επιστρέφει σωστές απαντήσεις. Δεν πρέπει να είναι προσβάσιμο από φοιτητές. |
| `get_exercise_attempts` | Deny | Allow (αν διδάσκει) | Allow | Οι φοιτητές δεν βλέπουν απαντήσεις ή προσπάθειες άλλων. |

## 5. Μηνύματα & Power Tools

| Εργαλείο | Student | Teacher | Admin | Αιτιολόγηση |
|---|---|---|---|---|
| `read_messages` | Allow (μόνο εαυτό) | Allow (μόνο εαυτό) | Deny | Ιδιωτικότητα και προστασία προσωπικών δεδομένων (GDPR). (Δες Ασάφεια 5) |
| `send_message` | Allow (ως εαυτός) | Allow (ως εαυτός) | Allow (ως εαυτός) | Το `from_user` πρέπει να αντιστοιχεί στον ίδιο τον χρήστη. |
| `run_sql` / `fetch_url` | Deny | Deny | Deny | Απαγορεύονται από το chatbot σύμφωνα με τους κανόνες της ομάδας. |

## 6. Γενικοί Κανόνες Ασφαλείας

1. **Ownership Validation:** Κάθε χρήστης αποκτά πρόσβαση μόνο σε δεδομένα για τα οποία έχει τα απαραίτητα δικαιώματα.
2. **Role Protection:** Μόνο ο Admin μπορεί να αλλάζει ρόλους.
3. **Student Isolation:** Οι φοιτητές δεν έχουν πρόσβαση σε δεδομένα, υποβολές ή βαθμούς άλλων φοιτητών.
4. **Teacher Restrictions:** Οι καθηγητές διαχειρίζονται μόνο τα μαθήματα στα οποία διδάσκουν.
5. **Sensitive Data Redaction:** Τα ευαίσθητα δεδομένα αφαιρούνται μέσω της `redact`.
6. **Chatbot Restrictions:** Τα `run_sql` και `fetch_url` απαγορεύονται μέσω του chatbot.
7. **Identity Validation:** Τα πεδία όπως `student_ref` και `from_user` πρέπει να αντιστοιχούν στον authenticated user.

## 7. Εκκρεμότητες & Ασάφειες (Open Questions)

- **Ασάφεια 1:** Επιτρέπεται το `list_users` αποκλειστικά στον Admin ή υπάρχουν εξαιρέσεις;
- **Ασάφεια 2:** Μπορεί το `reset_password` να χρησιμοποιηθεί με ασφάλεια μέσω chatbot, εφόσον δεν ζητάει τον παλιό κωδικό;
- **Ασάφεια 3:** Πρέπει το `list_courses` να εμφανίζει στους φοιτητές αποκλειστικά τα εγγεγραμμένα μαθήματα;
- **Ασάφεια 4:** Εφαρμόζει το `get_grades` περιορισμό ώστε κάθε φοιτητής να βλέπει μόνο τους δικούς του βαθμούς;
- **Ασάφεια 5:** Είναι σκόπιμη η απαγόρευση πρόσβασης του Admin στο `read_messages`;

---

**Σημείωση:** Όπου υπάρχει προϋπόθεση (π.χ. εγγραφή σε μάθημα ή ιδιότητα διδάσκοντα), απαιτείται επιπλέον έλεγχος εξουσιοδότησης κατά την εκτέλεση του εργαλείου (runtime authorization check).
